# React + TypeScript Odev Sayfasi

Bu proje, React ve TypeScript kullanilarak hazirlanmis modern bir egitim arayuzu icerir.

## Odev Kapsami

Bu uygulamada su gereksinimler karsilanmistir:

- Baslik (Header)
- Ana icerik alani
- Konu anlatimi (metin + ornekler)
- Gorsel ve kod ornekleri
- En az bir etkilesimli bilesen
- Alt bilgi (Footer)
- Fonksiyonel bilesenler
- Props ve type/interface tanimlari
- Bilesen tabanli yapi
- Responsive tasarim

Odev sayfasina gitmek icin uygulama acildiginda menuden **React Odev** baglantisini kullanabilir veya asagidaki adrese gidebilirsiniz:

- `/odev/react-tsx`

## Klasor Yapisi (Odev Ile Ilgili)

- `src/pages/ReactTsxOdev.tsx`
- `src/components/odev/LessonSection.tsx`
- `src/components/odev/TopicTabs.tsx`
- `src/components/odev/InteractiveQuiz.tsx`

## Calistirma Adimlari

1. Bagimliliklari kurun:

```bash
npm install
```

2. Gelistirme sunucusunu baslatin:

```bash
npm start
```

3. Tarayicida acin:

```text
http://localhost:5173
```

## Ek Komutlar

Tip kontrolu:

```bash
npm run typecheck
```

Uretim derlemesi:

```bash
npm run build
```
